# Bergz ZX 700 roadmap

Goal: a fun, intuitive FM groove box for grooves, bleeps, stabs and spaced-out
evolving pads, that slots into a music-production setup.

## v0.1 — first test build ✅
- 8-voice FM engine (4 starter algorithms), filter, envelopes, LFO
- 16-step sequencer with chords, 4-part drum machine
- Reverb / Delay / Phaser
- Motion recording (knob moves loop with the pattern), Scene A/B morph
- Mutate, scale lock, friendly knob labels
- Six original starter patches; landscape full-screen neon panel UI

## v0.2 — hands-on feedback round
- [ ] Fixes and tweaks from first play on the Pixel 9
- [ ] Save and load user patches and patterns
- [ ] Per-step parameter locks in the UI (hold a step, turn a knob)
- [ ] Pattern length and swing

## v0.3 — studio integration
- [ ] MIDI clock sync (follow a DAW or drum machine)
- [ ] MIDI note input (play Bergz from a keyboard) and MIDI CC for every knob
- [ ] Audio export: render a loop or a jam to WAV and share it
- [ ] Pattern chaining / song mode

## v0.4 — deeper sound
- [ ] Full FM algorithm set and the Voice editor screen (operators, ratios)
- [ ] Noise oscillator, glide, more FX types
- [ ] Drum kit choice and drum sound editing
- [ ] More original patches (pads, bleeps, stabs, basses)

## v0.5 — easy for anyone
- [ ] Guided first run ("turn Tone while it plays…")
- [ ] Undo for experiments and mutations
- [ ] Patch library screen

## Always
- Original Bergz patches only in anything shared or released. Any imported
  reference banks stay in the git-ignored `reference-banks/` folder.
